無理のない依存の減らし方

Runtime の機能を使う

chalk → util.styleText
uuid → crypto.randomUUID
throttle → util.throttle
debounce → util.debounce

既存の依存が基本

新しく足す前に、いまある依存で同じことができないか確かめる

重複した依存を消す

date-fns と dayjs
concurrently と npm-run-all2
chalk と picocolors

使われていない依存を消す

package.json に残っているだけの依存を、knip などで見つけて消す

無理のない減らし方をいくつか挙げます。1つは、Runtime の機能を使うこと。chalk の代わりに util.styleText、uuid の代わりに crypto.randomUUID が使えますし、throttle や debounce も最近 util に入りました。次に、新しく足す前に、既存の依存で同じことができないかを確かめること。それから、同じ役割の依存が重複していないか。date-fns と dayjs、concurrently と npm-run-all2、chalk と picocolors のように、気付くと両方入っていることがあります。最後に、package.json に残っているだけで使われていない依存を、knip などで見つけて消すことです。どれも、信頼する相手を増やさずに、減らす方向に働きます。
