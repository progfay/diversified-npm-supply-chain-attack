依存の減らし方

使われていない依存を消す

package.json に残っているだけの依存を、knip などで見つけて消す

重複した依存を消す

date-fns / dayjs
chalk / picocolors
concurrently / npm-run-all2

Runtime の機能を使う

uuid → crypto.randomUUID
throttle → util.throttle
rimraf → fs.rmSync

もしくは自作…？

依存の減らし方をいくつか挙げます。まず、package.json に残っているだけで使われていない依存を、knip などで見つけて消すこと。次に、同じ役割の依存が重複していないか。date-fns と dayjs、chalk と picocolors、concurrently と npm-run-all2 のように、気付くと両方入っていることがあります。それから、Runtime の機能を使うこと。uuid の代わりに crypto.randomUUID、rimraf の代わりに fs.rmSync が使えますし、throttle も最近 util に入りました。どれも、信頼する相手を増やさずに、減らす方向に働きます。では、いっそ自作するのはどうでしょう。
