依存の減らし方

使われていない依存を消す

package.json に残っているだけの依存を、knip などで見つけて消す

重複した依存を消す

date-fns / dayjs
chalk / picocolors
concurrently / npm-run-all2

Runtime の機能を使う

rimraf → fs.rmSync
uuid → crypto.randomUUID
util.throttle / util.debounce

もしくは自作...？

依存の減らし方として、おすすめの方法をいくつか挙げます。 1 つ目は使われていない依存を減らすことです。使わなくなったけど package.json にはうっかり残っているものなどがあったりします。 二つ目は同じような package が入っている場合、一つで賄えないか考えてみることです。 例えば日付操作ライブラリが複数入っていたり、 npm script の並列実行のための package が複数入っていたり。 ちなみに並列実行は pnpm でもできるので、どっちも消せる可能性があります。 三つ目は Runtime の機能を使うことです。 Node.js に標準で組み込まれている関数を使うことで rimraf や uuid などを削除できます。最近だと util.throttle や debounce が追加されたりとどんどん runtime の built-in 機能が拡充されてきています。 他にも package に頼らずに処理を自分で書くという方法もあります。
