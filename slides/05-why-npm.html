なぜ活発か？

依存する package へと広がっていく
機微情報 + package の publish 権限 が奪える → 次の攻撃へ

攻撃する側にとってコスパがいい

サプライチェーン攻撃はなぜこんなに活発なのでしょうか。攻撃する側の目線で考えてみます。 まず、パッケージを1つ乗っ取るだけで、それに依存するパッケージへと広がっていき、多くのプロジェクトに一気に届きます。 次に、届く先の開発者の PC や CI からは、 Credential に加えて publish 権限も盗めます。これを使って別のパッケージを乗っ取り次の攻撃につなげられます。 比較的少ない手間で大きな見返りが得られるため、攻撃する側にとってコスパがいいんだと分析しています。 一時期に比べると落ち着いてきた印象はありますが、この構造自体は変わっていません。
