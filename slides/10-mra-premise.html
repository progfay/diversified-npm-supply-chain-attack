Minimum Release Age は誰かが気付く前提

PhantomRaven(2025年): 2か月以上気付かれなかった

パッケージ本体は空っぽ。悪意あるコードは npm の外から取ってくるので、検査をすり抜けた

誰も気付かなければ、何日待っても防げない

次に Minimum Release Age です。pnpm のドキュメントにも、悪意あるリリースの多くは1時間以内に見つかって消される、と書かれています。つまりこれは、誰かが気付いて消してくれる、という前提の上に成り立っていて、その時間だけ待つ仕組みです。では、誰も気付かなかったらどうなるか。2025年の PhantomRaven では、2か月以上気付かれず、8.6万回インストールされました。パッケージ本体は空っぽで、悪意あるコードはインストールのときに npm の外のサーバーから取ってくる作りでした。スキャナーから見ると依存は0で、検査をすり抜けたんです。誰も気付かなければ、何日待っても防げません。
