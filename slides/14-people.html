狙われるのは、人とアカウント

node-ipc期限切れのメールドメインを取られ、アカウントを復旧された可能性
keyvメンテナの GitHub アカウントが乗っ取られた
chalk / debugメンテナがフィッシングメールに引っかかった

どの package も絶対に安全という保証はない

では、その人やアカウントは安全でしょうか。node-ipc では、期限切れになったメンテナのメールドメインを第三者に取られて、パスワードリセットでアカウントを復旧された可能性が指摘されています。keyv では、メンテナの GitHub アカウントそのものが乗っ取られました。chalk や debug では、メンテナが npm を装ったフィッシングメールに引っかかりました。どれも、多くの人に信頼されていた人気のパッケージです。人はミスをしますし、アカウントは狙われます。正直に言うと、信頼に足るかを見分ける確かな方法は、私もまだ答えを持っていません。どのパッケージも、絶対に安全という保証はないんです。
