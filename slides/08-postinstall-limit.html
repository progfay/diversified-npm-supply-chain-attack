postinstall を止めても、コードは動く

悪意あるコードは、パッケージを require / import した時点でも動かせる

npm install

postinstall が動く

✅ ブロックで止められる

npm start

パッケージが import される

❌ 止められない

node-ipc(2026年5月): require しただけで、クラウドの鍵・SSH 鍵・GitHub のトークンなどを盗む

AsyncAPI(2026年7月): 読み込むと、PC を外から遠隔操作できるマルウェアを仕込む

まず postinstall のブロックです。止められるのは、インストールのときに動くスクリプトだけです。でも、悪意あるコードは、パッケージを require や import した時点でも動かせます。1つめの例では、悪意あるバージョンを require しただけで、クラウドの鍵や SSH 鍵、GitHub のトークンなどが集められて、外に送られていました。2つめの例では、読み込むと、PC を外から遠隔操作できるマルウェアが仕込まれました。ブラウザに保存したパスワードや Cookie まで狙うものです。どちらも postinstall を使っていないので、ブロックしていても止まりません。
