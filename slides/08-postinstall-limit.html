postinstall を止めても、コードは入る

npm install

preinstall / postinstall

✅ ブロックできる

npm start npm test npm run lint

import "compromised-pkg"

❌ 止められない

まず postinstall のブロックです。止められるのは、npm install のときに動く preinstall や postinstall のスクリプトだけです。でも、そのあと npm start や npm test、npm run lint を実行すると、パッケージが import されます。悪意あるコードは、この import の時点でも動かせます。ここは、postinstall をブロックしていても止められません。
