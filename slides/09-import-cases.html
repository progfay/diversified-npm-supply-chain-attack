読み込むだけで動いた事例

require('node-ipc')

~/.aws/credentials, ~/.ssh, GitHub Token などを盗む

import '@asyncapi/specs'

PC を外から遠隔操作できるマルウェアを仕込む

import 'chalk'

ブラウザで fetch などをフックし、送金先を書き換える

実際に、そういう攻撃がありました。2026年5月の node-ipc は、週に約85万回ダウンロードされているパッケージですが、悪意あるバージョンは require しただけで、クラウドの鍵や SSH 鍵、GitHub のトークンなどを集めて送っていました。7月の AsyncAPI では、読み込むと PC を外から遠隔操作できるマルウェアが仕込まれました。ブラウザに保存したパスワードや Cookie まで狙うものです。2025年9月の chalk や debug では、改ざんされたコードがブラウザで読み込まれた時点で、fetch やウォレットの API をフックして、送金先を攻撃者のアドレスに書き換えていました。どれも postinstall は使っていないので、ブロックしていても止まりません。
