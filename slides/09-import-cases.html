読み込むだけで動いた事例

require('node-ipc')

~/.aws/credentials, ~/.ssh, GitHub Token などを盗む

import '@asyncapi/specs'

PC を外から遠隔操作できるマルウェアを仕込む

import 'chalk'

Browser にて仮想通貨の送金先を書き換える

実際に、 postinstall ではなく実行時を狙った攻撃がありました。例えば node-ipc では require しただけで credentials が盗まれたり、 AsyncAPI では外部から PC が遠隔操作されるマルウェアが仕込まれました。 chalk や debug では import すると仮想通貨ウォレットの送金先を書き換えるようになっていました。
