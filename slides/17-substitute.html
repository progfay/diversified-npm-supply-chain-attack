無理のない依存の減らし方

Node.js などの基盤の標準機能

例: chalk → util.styleText
uuid → crypto.randomUUID
throttle → util.throttle
debounce → util.debounce

すでに install している package を使う

例: 新しく足す前に、いまある依存で同じことができないか確かめる

無理のない減らし方として、まず、すでにあるもので代用できないかを考えます。1つは Node.js などの基盤の標準機能です。chalk の代わりに util.styleText、uuid の代わりに crypto.randomUUID が使えますし、throttle や debounce も最近 util に入りました。もう1つは、すでにインストールしているパッケージを使うこと。新しく足す前に、いまある依存で同じことができないかを確かめます。どちらも、信頼する相手を増やさずに済みます。
