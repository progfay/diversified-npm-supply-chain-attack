Minimum Release Age は誰かが気付く前提

その間だけ待つのが Minimum Release Age

次に Minimum Release Age です。これは、誰かが気付いて消してくれる、という前提の上に成り立っています。では、その誰かとは誰でしょう。今は、セキュリティ企業が、新しく公開されたバージョンを自動で検査しています。chalk や debug のときは、Aikido の監視が見つけました。メンテナ本人や利用者が気付いて報告することもあります。報告されると、悪意あるバージョンは取り下げられます。AsyncAPI は、公開から約4時間で取り下げられました。pnpm のドキュメントにも、悪意あるリリースの多くは1時間以内に見つかって消される、と書かれています。その間だけ待つのが、Minimum Release Age です。
